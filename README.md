# 🌸 ReproLab · 论文复现实验库

> 把每一次论文复现，都装进一个独立的小框里 ✨

🌐 **在线访问：** https://YOURNAME.github.io/reprolab/
💻 **本地运行：** node server.js 后打开 http://127.0.0.1:8123

## 这是什么 📚

我用来归档论文复现实验的小网站。

每篇论文一个独立的实验框，点进去能看到它依据的论文、各项指标的对比表、复现出来的图，
以及最后得出的结论。不统计「复现了几篇」「复现率多少」，只看单篇做得怎么样。

## 怎么跑 🚀

```bash
node server.js
```

然后用浏览器打开 http://127.0.0.1:8123

## 技术栈 🛠

原生 HTML + JS 单文件，零依赖；数据存在浏览器的 IndexedDB 里，随手导出成 JSON 备份。
